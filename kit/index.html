SKETCHBOOK KIT

Reusable pieces for slides and static web content in the style of the “learn anything” lightning-lesson slides. Every piece is plain HTML, CSS or SVG. Add sketchbook.css and sketchbook.js to a page, then paste in any chunk. Drop the icons and characters in as images anywhere.
